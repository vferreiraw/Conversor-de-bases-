# Conversor de bases

Conversor numérico simples feito com HTML, CSS e JavaScript puros.

Converte entre decimal, binário, octal, hexadecimal, base 32 e base 36, nos dois sentidos.
Suporta números negativos e muito grandes (BigInt).

## Como usar

Abra o `index.html` no navegador. Não precisa instalar nada.

## Estrutura

- `index.html`: página
- `style.css`: estilos
- `script.js`: lógica de conversão
