# Conversor-de-bases-

O site foi criado a partir de um projeto da faculdaede Análise e Desenvolvimento de Sistemas da Fatec Ribeirão Preto, a pedido do professor Carlos Danilo Gaioli Euzebio. O site foi elaborado em conjunto com o meu colega Rentato Oliveira. 

O site funciona da seguinte maneira: o úsuario insere um número e seleciona a base em que está o número inserido. Após isso, o site mostra mesmo número convertido a outas bases (decimal, binário, octadecimal, hexadecimal, base 32 e base 36).
